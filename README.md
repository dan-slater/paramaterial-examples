# paramaterial-examples

Repeatable examples of mechanical test data (tensile, compression, cyclic) processed with [paramaterial](https://github.com/dan-slater/paramaterial), a Python package for stress-strain data processing.

Each folder under `examples/` holds raw data, the processing notebook or script, and the resulting plots and parameter tables.

Install the package with `pip install paramaterial`. Documentation: https://dan-slater.github.io/paramaterial/
